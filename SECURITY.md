# Security Policy

## Reporting a Vulnerability

Please report potential security issues using GitHub Issues in this repository.
If private coordination is required, use a maintainer-controlled security contact
address (placeholder): `security@example.com`.

## Scope

This project includes OpenCL wrapper runtime and RT pack-loading paths. Reports
should include reproducible steps, affected commit/tag, and expected impact.

## Response Expectations

Maintainers will acknowledge valid reports and provide triage status updates.
Fixes and advisories are handled through normal release/CM process.
