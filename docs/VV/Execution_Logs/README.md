# Execution Logs

Este directorio almacena evidencias de ejecucion de pruebas y builds relevantes
para V&V del proyecto.

## Uso
- Los logs de ejecucion se guardan en este directorio.
- Para evidencia de gate, usar subcarpetas bajo `GATES/`.
- Estructura recomendada de gate evidence: `GATES/G0/`, `GATES/G1/`, etc.

## Nota de trazabilidad
- Registrar fecha, comando ejecutado, resultado y referencia al requisito/test
  asociado cuando aplique.
